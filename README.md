# Daily OS – Habit & Productivity Tracker

Daily OS is a personal productivity dashboard designed to help track and review daily habits, activities, learning, and personal growth in one place.

## Features

- 📚 Book reading tracker
- ✍️ Daily writing tracker
- 🏋️ Exercise and workout tracking
- 🔥 Calories burned tracking
- 📖 Book reviews
- 🧠 New things learned each day
- ✅ Good things that happened
- ⚠️ Bad things that happened
- 🌅 Morning journal
- 🌙 Night journal
- 📊 Daily task review
- 📈 Personal monitoring data
- 📝 Article and Substack writing progress

## Purpose

The goal of Daily OS is to create a simple personal system for tracking everyday activities and building consistent habits.

Instead of using multiple apps, Daily OS brings important daily activities into a single dashboard.
